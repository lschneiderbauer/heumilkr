# CVRP instance data by Christofides and Eilon, 1969

A collection of CVRP instances by Christofides and Eilon, 1969, provided
courtesy of
[CVRPLIB](https://galgos.inf.puc-rio.br/cvrplib/en/instances). See
[CVRPLIB](https://galgos.inf.puc-rio.br/cvrplib/en/instances) for
visualizations of the instances and their solutions as well as a
multitude of alternative instance data.

## Usage

``` r
cvrplib_E
```

## Format

### `cvrplib_E`

A list of CVRP instances as "`cvrplib_instance`" objects. The instances
can be directly fed into solver algorithm, e.g. via
[`clarke_wright_cvrplib()`](https://lschneiderbauer.github.io/heumilkr/reference/clarke_wright_cvrplib.md).
